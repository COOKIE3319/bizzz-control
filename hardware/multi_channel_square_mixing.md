# 方案 B：多 GPIO 方波电阻混合（硬件设计）

目标：用 3 路独立频率的方波（LEDC 硬件产生，不占 CPU），经电阻网络相加后驱动蜂鸣器，
实现**真正的多音同时发声**（和弦），并支持音量/包络调节。固件暂不改动。

---

## 1. 原理：等值电阻求和 = 多电平 DAC

n 路 3.3V 方波各串联一个 **相同阻值** 的电阻汇到同一点，该点电压是各路电平的**平均值**：

| 同时为高的路数 | 节点电压（近似） | 电平 |
| :--- | :--- | :--- |
| 3 路高 | 3.3 V | 3 |
| 2 路高 | 2.2 V | 2 |
| 1 路高 | 1.1 V | 1 |
| 0 路高 | 0 V | 0 |

也就是说，3 路方波的"和"被电阻网络变成了 **4 个电平的阶梯波形**（3-bit DAC）。
把它送进蜂鸣器的驱动管（V→I 转换）后，蜂鸣器振膜按这个和信号运动 →
**三个频率同时存在**（外加和频/差频，听起来更"厚"，是老式 chiptune 的质感）。

> 为什么必须"每路一个电阻"：GPIO 直接并联 = 短路，会烧；电阻同时限流和等权求和。

## 2. 接线方案 B1（最简，保留现有模块，零有源元件）

```
ESP32-S3                        蜂鸣器模块（三脚，低电平触发）
GPIO15 ──[1kΩ]──┐
GPIO4  ──[1kΩ]──┼──[1kΩ]──► IO
GPIO5  ──[1kΩ]──┘
3V3 ───────────────────────► VCC
GND ───────────────────────► GND
```

- 三个 1kΩ 等值电阻在 IO 前汇成"求和节点"，再串 1kΩ 进模块 IO（限流、防过冲）
- 模块内部的三极管本身就是一个 V→I 转换：IO 电压越低，驱动电流越大
- **共地必须接好**（模块 GND 与 ESP32 GND 直连，尽量短）
- 模块是低电平触发，所以"全低 = 最响"，求和波形相当于取反，不影响和弦关系

优点：只加 4 个 1kΩ 电阻，不动固件、不拆模块。
缺点：模块内部输入级可能是简单三极管（线性较好），也可能是带阈值的驱动（线性一般），
实验时先用万用表量节点电压确认 4 个电平存在。

---

## 3. 接线方案 B2（推荐，效果更可控）

把三脚模块换成 **裸无源蜂鸣器（2 脚）**，自己搭一级 NPN 驱动，线性度和音量控制都更好：

```
GPIO15 ──[1kΩ]──┐
GPIO4  ──[1kΩ]──┼───► 2N3904 基极（B）
GPIO5  ──[1kΩ]──┘
                    B ──[100kΩ]── GND        （基极下拉，抗干扰/泄放）
                    E ──[47Ω]── GND          （发射极负反馈，改善线性/限流）
                    C ──► 蜂鸣器(–)
3V3 ──────────────────► 蜂鸣器(+)
```

- 三个 1kΩ 把三路方波"电流相加"进基极，集电极电流约 β×Ib，蜂鸣器获得模拟和信号
- 100kΩ 下拉保证全部 GPIO 为低时基极可靠关断
- 47Ω 发射极电阻把 V→I 转换变成近似线性，并可限制最大电流
- 蜂鸣器若是有源型（内部振荡），**不能这样用**，必须换无源型；有源型只适合通断

## 4. 引脚选择

| 用途 | 引脚 | 说明 |
| :--- | :--- | :--- |
| 通道 1 | **GPIO15** | 现有蜂鸣器引脚，复用 |
| 通道 2 | **GPIO4** | DevKitM-1 排针可用 |
| 通道 3 | **GPIO5** | DevKitM-1 排针可用 |
| （可选）通道 4 | GPIO6 / GPIO7 | 想要 4 音和弦时用，最多 5 电平 |

**必须避开的引脚**（ESP32-S3-DevKitM-1 + 8MB 内嵌 PSRAM）：
`GPIO0/3/45/46`（strapping）、`GPIO19/20`（USB）、`GPIO26~37`（SPI Flash / PSRAM）、
`GPIO39~42`（JTAG）、`GPIO43/44`（UART0）。

LEDC 资源：S3 有 8 通道 / 4 定时器；**3 路不同频率需要 3 个定时器**（刚好够），
4 路时第 4 路只能与某一路共用定时器（同频）。

## 5. 音量与包络怎么加（三档强度）

### 5.1 软件占空比（零硬件，最省事）
每路方波占空比从 50% 往小调 → 基波幅度下降 → 变小声（音色会略变亮）。
缺点：幅度和音色耦合，不适合精细包络。

### 5.2 串联衰减（简单、音色不变）
在蜂鸣器供电支路串 100Ω~1kΩ 电位器（或固定电阻选档）。
优点：纯衰减、音色不变；缺点：手动，不能做包络。

### 5.3 可选 VCA（能做 ADSR 包络，硬件多 2 个元件）
```
GPIO（第 4 路，PWM 20kHz）──[10kΩ]──┬──[100nF]──GND   （RC 低通 → 模拟音量电压）
                                     └── 2N7000/BS170 栅极（JFET/MOS 作可变电阻）
```
JFET 串在蜂鸣器回路里，PWM 占空比 → RC 电压 → 等效电阻 → 音量。
固件用 20kHz PWM 更新占空比即可做淡入淡出/包络。

## 6. 搭建与验证步骤

1. **先只接通道 1**（GPIO15 → 1kΩ → 模块 IO），确认单音正常
2. 接上通道 2、3 的 1kΩ，暂不接 GPIO（悬空），用万用表量求和节点：
   - 三路全低 ≈ 0V，全高 ≈ 3.3V，中间两档 ≈ 1.1V / 2.2V（±0.2V 正常）
   - 若测得一直是 0.7V，说明模块输入端有钳位，属正常（电流求和仍在工作）
3. 三路同时输出不同频率（262 / 330 / 392 Hz），听是否同时存在三个音（会有拍频/粗糙感）
4. 接示波器看节点：应看到 4 电平阶梯波；接 B2 时看集电极电流波形
5. 量模块 VCC 电流（正常 <20mA），摸一下三极管温度（烫手就加大发射极电阻）

## 8. 后续软件接口（本次不改，仅规划）

固件侧预留一个"多通道输出后端"：

- 3 个 LEDC 通道（GPIO15/4/5）分别持有 voice 的频率
- 音符→voice 分配：单音占 1 路；和弦按音高分配（最多 3 路），超出时快速分解
- 音量：每路 `ledcWrite()` 的占空比（0~50%）
- 包络：主循环里按 10ms 步进更新占空比（淡入/淡出）
- BLE 新增命令：`VOL <0-100>`、可选的 `ENV <a> <d> <s> <r>`
- 现有简谱解析 / 曲谱格式 / 播放模式 / 网页控制全部不变

## 9. 风险与注意

- **绝不把两个 GPIO 直接拧在一起**，必须各串电阻
- 求和电阻必须等值，否则音色不平衡（可用 2 个并联/串联凑值）
- 模块若带施密特触发/比较器输入，混合会退化成"按多数电平通断"，此时改用 B2
- 蜂鸣器是有源型（内部振荡）时，多音会糊成一团，只能用无源型
- 3V3 电源要能提供瞬态电流，建议在模块 VCC 旁并 10µF + 100nF
- 音频线尽量短，远离 USB 数据线，减少干扰
